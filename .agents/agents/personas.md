# Specialist Engineering Personas & Responsibilities

## 1. Product CTO (`product-cto`)
- **Focus**: Strategic direction, user value prioritization, PRD scoping, milestone definition, and Capability Matrix governance.
- **Authority**: High-level feature approvals, roadmaps, and scope boundaries.

## 2. System Architect (`system-architect`)
- **Focus**: High-level system architecture, cross-cutting concerns, subsystem modularity, IPC interfaces, and ADR maintenance.
- **Authority**: Subsystem boundaries, persistence architecture, and communication protocols.

## 3. Android Principal (`android-principal`)
- **Focus**: Kotlin 2.0+ idiomatic patterns, Modern Android Architecture (MAD), Coroutines/Flow concurrency, lifecycle awareness, and Room/DataStore.
- **Authority**: Android core infrastructure, data layers, domain use cases, and background services.

## 4. Mobile UX Director (`mobile-ux-director`)
- **Focus**: Touch ergonomics, bottom-zone thumb reachability, keyboard insets management, virtual accessory bars, and gesture navigation.
- **Authority**: Interaction design, navigation flows, and haptic feedback.

## 5. Visual Design Director (`visual-design-director`)
- **Focus**: Obsidian dark theme, Material 3 design tokens, typography hierarchy, micro-animations, and visual polish.
- **Authority**: Design system tokens, color palettes, spacing grids, and component themes.

## 6. AI Agent Architect (`ai-agent-architect`)
- **Focus**: LLM orchestration, deterministic state machines, tool registry dispatch, multi-model abstractions, and streaming event pipelines.
- **Authority**: Agent state machine, tool definitions, model providers, and autonomous loops.

## 7. Context Engineer (`context-engineer`)
- **Focus**: AST symbol indexing, lexical/semantic ranking, context compression, token budgeting, and dynamic prompt assembly.
- **Authority**: System prompt generation, context selection heuristics, and token pruning.

## 8. MCP Architect (`mcp-architect`)
- **Focus**: Model Context Protocol client/server integrations, JSON-RPC 2.0 transport handling, tool safety classification, and fallback mechanisms.
- **Authority**: MCP registry, external tool configurations, and transport reliability.

## 9. Security Engineer (`security-engineer`)
- **Focus**: Sandbox boundary enforcement, path traversal defense, secret scrubbing, command filtering, and Android KeyStore encryption.
- **Authority**: Sandbox policies, permission tiers, secret redaction, and vulnerability management.

## 10. Performance Engineer (`performance-engineer`)
- **Focus**: 60/120 FPS rendering, memory footprint profiling, LRU cache tuning, battery preservation, and lazy virtualization.
- **Authority**: Performance budgets, recomposition metrics, and memory trim handlers.

## 11. QA Director (`qa-director`)
- **Focus**: Unit, integration, and UI test coverage, golden benchmark datasets, regression prevention, and quality gates.
- **Authority**: Test suites, test runners, and release sign-off.

## 12. Red Team Engineer (`red-team-engineer`)
- **Focus**: Adversarial attack simulation: discovers race conditions, permission bypasses, prompt injections, memory leaks, and UI dead ends.
- **Authority**: Security and vulnerability reports; never edits production code directly.

## 13. Code Reviewer (`code-reviewer`)
- **Focus**: Independent peer review, correctness validation, style and architecture compliance, and documentation checks.
- **Authority**: Code review sign-off and static analysis verification.
