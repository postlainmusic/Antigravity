# Design System Tokens Specification

## 1. Color Tokens (Obsidian Theme)
- `DeepObsidian`: `#090B10` (Primary App Canvas Background)
- `DarkSurface`: `#11141D` (Card / Panel / Drawer Background)
- `DarkSurfaceElevated`: `#181D29` (Floating Elements, Modal Sheets)
- `DarkBorder`: `#222938` (Structural Borders)
- `DarkBorderSubtle`: `#1B202D` (Inner Dividers)
- `IndigoGlow`: `#6366F1` (Primary Brand Accent)
- `CyanNeon`: `#38BDF8` (Secondary Action Accent)
- `EmeraldSuccess`: `#10B981` (Diff Additions, Passed Checks)
- `AmberWarning`: `#F59E0B` (Pending Approvals, Warnings)
- `RoseError`: `#EF4444` (Diff Deletions, Errors, Danger Tiers)

---

## 2. Spacing Grid Tokens
- `SpacingXS`: `4.dp`
- `SpacingSM`: `8.dp`
- `SpacingMD`: `12.dp`
- `SpacingLG`: `16.dp`
- `SpacingXL`: `24.dp`
- `Spacing2XL`: `32.dp`

---

## 3. Corner Radius Tokens
- `RadiusSmall`: `6.dp` (Badges, syntax tags, chips)
- `RadiusMedium`: `10.dp` (Buttons, text fields)
- `RadiusLarge`: `16.dp` (Cards, preview containers)
- `RadiusSheet`: `24.dp` (Top corners of bottom sheets)

---

## 4. Typography Scale Tokens
- `DisplayLarge`: 28sp / Bold (Screen Titles)
- `HeadlineMedium`: 22sp / SemiBold (Section Headers)
- `TitleMedium`: 16sp / Medium (Card Titles, App Bar)
- `BodyLarge`: 15sp / Regular (Chat bubbles, editor text)
- `BodyMedium`: 13sp / Regular (Secondary descriptions)
- `LabelSmall`: 11sp / Medium (Badges, timestamps)
- `CodeMono`: 13sp / Monospace (JetBrains Mono / Source Code Pro)
