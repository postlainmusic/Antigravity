# Documentation Skill

## Purpose
Maintains clear, accurate, up-to-date documentation reflecting real codebase architecture, operational runbooks, and implementation decisions.

## Documentation Index
- `README.md`: High-level product overview, features, quickstart, screenshots.
- `docs/ARCHITECTURE.md`: Subsystem architecture, layer boundaries, data flow diagrams.
- `docs/PROJECT_MEMORY.md`: Persistent vision, current progress, known tech debt.
- `docs/DECISIONS.md`: Chronological Architecture Decision Records (ADR).
- `docs/ROADMAP.md` & `docs/TASKS.md`: Feature milestones and task tracking.
- `docs/MCP_REGISTRY.md`: Catalog of registered MCP servers and safety tiers.
- `docs/SECURITY.md`: Sandbox policies, secret management, threat models.
- `docs/TESTING.md`: Test strategies and execution commands.
- `docs/RELEASE.md`: Release verification and build signing checklist.
