# /build-feature Meta-Skill

## Purpose
Primary orchestrator for implementing new features from natural language intent to verified, production-ready code.

## Execution Sequence
1. **Understand & Discover**:
   - Activate `product-discovery` and `technical-research` to clarify specifications and edge cases.
2. **Architect & Plan**:
   - Activate `android-architecture` and `ai-agent-architecture` to outline data flow, state models, and file changes.
3. **Implement**:
   - Write cleanly decoupled code across Data, Domain, and Presentation layers.
   - Use `design-system` and `compose-ui` for UI components.
4. **Test & Verify**:
   - Activate `testing-engineering` to create unit and UI tests.
   - Run test suite and fix any regressions.
5. **Review & Polish**:
   - Activate `code-review` and `ui-review`.
   - Update `docs/PROJECT_MEMORY.md` and `docs/TASKS.md`.
