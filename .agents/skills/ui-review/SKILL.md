# UI Review Skill

## Purpose
Evaluates visual design quality, aesthetic polish, and interactive responsiveness to ensure a premium, cinematic experience.

## Review Checkpoints
1. **Visual Hierarchy & Restraint**:
   - Clear visual anchor points; purposeful use of color tokens without neon clutter.
2. **Spacing & Alignment**:
   - Adherence to the 4dp/8dp spacing grid across all cards, paddings, and button bars.
3. **Multi-State Completeness**:
   - Verify Idle, Loading (shimmer/skeleton), Active (streaming), Empty, and Error states.
4. **Adaptive Responsiveness**:
   - Test layout fidelity across Compact phones (360dp - 412dp), Medium foldables (600dp), and Expanded tablets (840dp+).
