# Technical Research Skill

## Purpose
Systematically resolves technical unknowns using authoritative, up-to-date documentation and benchmarks before coding.

## Authoritative Hierarchy
1. **Official Platform Docs**: Android Developers (`developer.android.com`), Kotlin Docs (`kotlinlang.org`), Jetpack Compose Docs.
2. **Standard & Model Specs**: Model Context Protocol (`modelcontextprotocol.io`), OpenAI/Google/Anthropic API Docs.
3. **Official Open-Source Repositories**: Source code, issue trackers, and release notes on GitHub.

## Workflow
1. Formulate specific technical queries (e.g. "How to stream SSE with Ktor 3.0").
2. Query authoritative docs / web search.
3. Compare candidate solutions against project constraints (memory, performance, mobile battery).
4. Summarize trade-offs and record resulting decisions in `docs/DECISIONS.md`.
