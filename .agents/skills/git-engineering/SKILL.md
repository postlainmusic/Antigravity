# Git Engineering Skill

## Purpose
Integrates seamless, safe Git version control workflows into the mobile IDE.

## Key Capabilities
1. **Repository Inspection**:
   - Query staged, unstaged, and untracked files.
   - Extract branch lists and commit logs.
2. **Visual Diff Viewer**:
   - Unified and split diff modes with colored additions (green) and deletions (red).
   - Per-hunk staging and discard capabilities.
3. **Commit & Branch Operations**:
   - Conventional commit message generator powered by AI summary of changes.
   - Branch creation, switching, and safe checkout validation.
4. **Safety Mechanisms**:
   - Protect against unintended data loss before destructive operations.
