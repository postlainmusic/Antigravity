# Design System Skill

## Purpose
Enforces a consistent, premium, cinematic developer theme across all screens and components.

## Palette & Tokens
- **Background Deep**: `#090B10`
- **Surface Dark**: `#11141D`
- **Surface Elevated**: `#181D29`
- **Border Subtle**: `#222938`
- **Brand Accent**: `#6366F1` (Indigo Glow)
- **Secondary Accent**: `#38BDF8` (Cyan Neon)
- **Success Tone**: `#10B981` (Emerald)
- **Warning Tone**: `#F59E0B` (Amber)
- **Error Tone**: `#EF4444` (Rose Red)
- **Syntax Monospace**: JetBrains Mono / Source Code Pro

## Elevation & Shapes
- Radius Small: `6.dp` (Badges, tags)
- Radius Medium: `10.dp` (Buttons, input fields)
- Radius Large: `16.dp` (Cards, dialogue panels)
- Radius Sheet: `24.dp` (Top corners of modal sheets)

## Typography Scale
- Display: 28sp / Bold
- Title: 20sp / SemiBold
- Body Large: 16sp / Regular
- Body Medium: 14sp / Regular
- Code: 13sp / Monospace (JetBrains Mono)
