# Preview Engineering Skill

## Purpose
Provides instantaneous visual feedback on generated or modified web, mobile, and UI code via an integrated preview runtime.

## Capabilities
1. **Local Preview Server**:
   - Spawns local HTTP/WebSocket static and dev servers.
   - Dynamic port allocation with automatic conflict resolution.
2. **Embedded WebView & Inspector**:
   - Sandboxed Android WebView rendering HTML5/CSS/JS applications.
   - Live bridge capturing `console.log`, `console.error`, and runtime uncaught exceptions directly to the IDE logs.
   - Interactive viewport switching (Mobile Phone, Tablet, Desktop viewports).
3. **Live Reload**:
   - File watch listener triggering instant WebView DOM reload upon agent code save.
